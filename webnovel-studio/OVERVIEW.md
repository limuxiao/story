# 网文写作学习目标管理台 · 交付说明

一个帮你**系统练笔、长期进阶**的网文写作工作台。前端 Vite + Vue3 + TS，后端 NestJS（TypeScript）操作本地 SQLite 数据库，数据全部落在 `server/data/studio.db` 文件里，关掉程序也不丢。

---

## 一、怎么跑起来

项目根目录 `webnovel-studio/` 下是两个子包：`server`（后端）、`web`（前端）。

```bash
# 1. 安装依赖（只需第一次）
cd webnovel-studio
npm install            # 装根目录的 concurrently
npm run install:all   # 装 server 与 web 的依赖

# 2. 编译后端（NestJS 需要先 build 成 JS）
npm run build

# 3. 一键启动前后端
npm run dev
#   后端 → http://localhost:5178/api
#   前端 → http://localhost:5273   （浏览器打开它）
```

也可以分开跑：
```bash
npm run dev:server    # 终端 A：起后端
npm run dev:web       # 终端 B：起前端
```

数据初始化在后端启动瞬间自动完成（建表 + 灌入 18 个模块的教程与练习 + 1 个示例九宫格作品），无需手动执行。

> 说明：你提到「用 next.ts 搭后端」。next.ts 不是常见框架，按前后端分离的意图我用了 **NestJS**（TypeScript 生态里最主流的 REST 后端框架，与 Vue 前端配合最顺）。如果你特指 Next.js（React 系），告诉我，我可以换成 Next.js 的 API 路由版本。

## 二、页面结构（完全按需求落地）

```
┌──────────────────────────────────────────────────────────┐
│  Header  顶部：标题 / 当前阶段 / AI 设置入口 / 重置         │
├──────────┬───────────────────────────────┬────────────────┤
│ 左侧导航 │  中部 Wrapper（路由出口）      │ 右侧 AI 聊天  │
│ 18 个环节│  总览 / 计划 / 模块页 /       │ 陪练面板，    │
│ + 实战   │  实战档案 / 历史              │ 按当前模块   │
│          │                              │ 上下文分析   │
├──────────┴───────────────────────────────┴────────────────┤
│  Footer  底部：统计概要 / 链接                              │
└──────────────────────────────────────────────────────────┘
```

- **总览仪表盘**：今日练笔、统计卡、分阶段进度、35 天热力图、最近练习 / 最近诊断。
- **分阶段学习计划**：4 个阶段（立基 → 塑形 → 生肉 → 收魂），约 24 周，每阶段只盯一件事。
- **模块页（每个练习环节一个页面）**：教程（可逐课「标记已读」）+ 练习区（写正文 → 点「AI 分析」出诊断报告）。
- **实战档案**：参考 `story_study/doc/网文制作.html` 的九宫格结构（书名/类型/立意/主题/一句话梗概/世界观/人物/剧情总纲/分卷大纲/当前问题），支持整体诊断。
- **历史**：所有练习与诊断记录的回看。

## 三、课程地图：18 个环节 / 4 阶段 / 约 24 周

> 说明：下面的环节不是照抄你最初列举的那几个，而是我按**专业网文创作的完整能力地图自主补全**的——网文真正要练的，远不止"灵感、人物、情节"那几项。你最初点名的环节已全部包含在内（灵感立意、世界观、人物、情节、爽点、场景、对话、节奏、实战），并补上了被严重低估却决胜的 9 块：**题材定位、金手指、大纲细纲、伏笔线索、冲突设计、代入感、黄金三章、书名包装、网感运营**。

| 阶段 | 周次 | 环节 | 模块 id |
|------|------|------|---------|
| 1 立基 | 1–5 周 | 题材定位与市场判断、灵感与立意、世界观与设定、金手指与核心设定 | genre、inspiration、world、goldfinger |
| 2 塑形 | 6–11 周 | 人物塑造、情节与结构、大纲与细纲规划、伏笔与线索管理、冲突设计与阻碍制造 | character、plot、outline、foreshadow、conflict |
| 3 生肉 | 12–18 周 | 爽点、代入感与读者心理、节奏与悬念、黄金三章与开篇、场景与描写、对话与文笔 | climax、immersion、pacing、opening、scene、dialogue |
| 4 收魂 | 19–24 周 | 书名简介与包装、综合实战、网感数据与签约运营 | packaging、practice、market-sense |

共 **63 节课 + 63 道练习题**，每个练习都有「题目要求 / 评分细则 / 参考写法」，每个环节都能独立出「AI 诊断报告」。

各模块按阶段在左侧导航分组展示，点击即进入该环节的「教程（可逐课标记已读）+ 练习区（写正文 → AI 分析）」页面。导航、阶段计划均为后端动态渲染——后续若想增删环节或调整阶段归属，只改后端 `server/src/seed/curriculum/` 下的课程数据并重启即可，前端零改动。

## 四、AI 分析怎么用

两种模式，自动切换：

1. **本地诊断（默认，无需任何配置）**：内置一套写作规则诊断器，按「概念新鲜度 / 情感钩子 / 立意深度 / 可执行性」等维度打分、给优缺点和改写建议。零依赖、离线可用，适合先跑通流程。
2. **接入真实大模型**：点右上角「AI 设置」，填接口地址（如 `https://api.openai.com/v1`）、模型名、密钥，保存后所有「分析 / 聊天」自动改走大模型，诊断质量大幅提升。

右侧 AI 陪练面板会读取你正在写的草稿（练习页勾选「带上我的草稿」），针对当前环节提问。

## 五、数据与重置

- 数据库文件：`server/data/studio.db`（SQLite）。
- 备份：直接复制这个文件即可。
- 重置个人数据（练习、诊断、聊天、进度，不动教程）：总览页或调用 `POST /api/danger/reset`。
