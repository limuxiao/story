三个月学习计划（每周目标）

📅 第 1 个月：后端底座搭建，写出标准REST接口（重点：Nest+TypeORM+Redis+Docker本地环境）

第1周：NestJS基础

  • 搭建Nest项目，理解Module/Controller/Service/Provider
  • 熟悉依赖注入、基础模块划分
  • 学习DTO、Pipe参数校验，统一返回格式

第2周：TypeORM + MySQL

  • Entity定义、主键、字段约束、索引
  • Repository、基础CRUD、QueryBuilder
  • Migrations迁移管理，学会生成、执行迁移
  • 一对多、多对一关系映射

第3周：Redis、鉴权、权限、缓存策略

  • Nest集成Redis，基础缓存封装
  • JWT登录、刷新令牌、Guard鉴权
  • 分布式锁、接口限流简单实现
  • 缓存雪崩、穿透、击穿方案理解

第4周：Docker + docker-compose 本地整套环境

  • Docker基础、Volume、网络
  • 编写Nest多阶段Dockerfile
  • docker-compose编排 Nest + MySQL + Redis
  • 本地一键拉起开发环境，完成一个完整资源REST（用户/文章）CRUD项目

✅ 月度产出：一个可本地docker启动的RESTful后端项目，带用户模块、JWT鉴权、Redis缓存

📅 第 2 个月：运维上线能力 + 前端对接（重点：Linux / Nginx / 备份 / 前端）

第5周：Linux基础 & 服务器安全

  • 常用命令：进程、磁盘、网络、日志查看
  • systemd、crontab定时任务、防火墙
  • SSH密钥登录，服务器安全加固

第6周：Nginx + HTTPS部署

  • Nginx反向代理配置，转发到后端服务
  • acme.sh申请SSL证书，配置HTTPS
  • 跨域、静态资源配置

第7周：MySQL备份恢复 + 线上部署项目

  • mysqldump脚本，crontab定时自动备份
  • 备份恢复演练
  • 服务器上使用docker-compose部署你的后端项目，公网可访问

第8周：前端开发，对接REST接口

  • 选定一套前端（Vue3 / React / Next）
  • 封装Axios请求、统一错误处理
  • 开发登录页面、列表页、新增编辑页，联调后端

✅ 月度产出：公网可访问完整项目：后端REST服务 + 前端页面 + HTTPS + 自动数据库备份

📅 第 3 个月：进阶可观测、CI/CD、优化、综合项目打磨

第9周：Prometheus + Grafana 监控

  • Nest暴露指标，接入Prometheus
  • Grafana面板搭建：QPS、耗时、错误率、服务器资源
  • 配置告警通知

第10周：Loki日志收集 + 排障能力

  • Loki+Promtail收集容器日志
  • 学习慢接口排查、数据库慢SQL分析、Explain

第11周：CI/CD自动化部署 Github Actions

  • 编写workflow：提交代码 → 构建镜像 → 推送镜像仓库 → 服务器更新服务
  • 学习单元测试Jest，给Service层写测试用例

第12周：整体重构优化、查漏补缺、项目收尾

  • 完善接口文档Swagger
  • 整理规范、异常处理、优化缓存策略
  • 复盘整个链路，标记薄弱点后续学习（K8s、MQ等）

✅ 月度产出：带监控、日志、自动部署的生产级Demo项目，整套链路闭环

打卡清单

提示：K8s、消息队列等高可用内容不纳入3个月强制目标，学完主线后按需拓展
