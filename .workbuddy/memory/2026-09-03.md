## 接入 DeepSeek（用户提供的 apikey 代配）
- 后端 ai.service 本就走 OpenAI 兼容 /chat/completions，DeepSeek 兼容，无需改代码。
- 配置写进 settings 表：ai_base_url=https://api.deepseek.com/v1、ai_model=deepseek-chat、ai_api_key=用户key（经 PUT /api/settings/ai）。
- 配置每次请求实时读取，写入立即生效、无需重启。
- 验证：health aiEnabled=true；analyze 与 chat 均返回 source:ai（真实 DeepSeek 回复）。
- 坑：聊天接口字段是 body.message（单条），不是 messages（数组）；测试时传错字段会让 chat_messages.content 为 NULL 触发 500。前端 AiPanel 传的是正确字段 message。
- 已加 .gitignore 排除 server/data/（含 apikey）与 .env。

## 停止服务（用户要求暂停）
