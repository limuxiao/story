好故事评判体系

多引擎诊断 · 快速检查 · 理论透镜 · 不是清单，是路径
本体系整合麦基、特鲁比、斯奈德、克龙、福斯特、哈蒙等叙事理论，但拒绝“打分求和”式的清单堆砌。它提供一条诊断路径：先用快速检查判断雏形是否值得继续，再用三个理论透镜逐层深挖病因。

为什么不是清单，而是“引擎 + 透镜”

清单式标准的问题是：它把“共情”“冲突”“主题”“人物”并列成几十条，逐项打分。但故事不是并列的——读者先在乎一个人，才会关心她的冲突；读者先感到压力，才会在乎她的选择；读者先看见她改变，才会带走一个主题。

所以这个体系用“引擎”代替“维度”：故事至少需要三台引擎同时运转，一台负责抓人（人物与欲望），一台负责推人（压力与因果），一台负责留人（改变与余味）。任何一台熄火，故事就停在那台引擎对应的位置上。

“透镜”则是诊断工具：同一个问题，用麦基的透镜看是“鸿沟够不够”，用克龙的透镜看是“错误信念有没有被挑战”，用福斯特的透镜看是“情节是因果还是编年”。多透镜交叉诊断，比单一口径的清单更能定位真问题。

先快速检查判断“值不值得写”，再用三台引擎逐级诊断“哪里断了”。

快速检查法 5 个问题 · 判断雏形是否值得继续

在投入大纲或正文之前，用五个问题快速扫描故事梗概。不需要打分，只需要判断“有没有危险信号”。五个问题中任何一个亮红灯，先修它，不要往下写。

1
主角想要的东西，能不能用一句不带抽象词的话说出来？
克龙指出，大脑从第一页就在问：“谁的故事？发生了什么？赌注是什么？”如果主角的目标是“拯救天下”“寻找自我”“打败邪恶”，大脑无法把它转化为可追踪的叙事线索。[reference:0]
只能说“她想拯救百姓”，说不出她“具体想救谁、想得到什么、想保护什么”。
2
主角在故事前段有没有一个“她本可以不这么做”的岔路口？
麦基认为，人物真相只能通过压力下的选择来揭示。如果主角从第一页到最后一页都在被事件推着走，她就没有“人物”，只有“功能”。[reference:1]
主角的所有行为都是“换谁都得这么干”，读者感觉不到她的意志。
3
反派有没有做过一件具体的、让读者恨得起来的事？
特鲁比把“对手”定义为“与主角争夺同一个目标的人”，而不是单纯的“坏人”。对手的恶必须有具体动作，直接造成主角的痛苦，否则威胁感不成立。
只能说“反派很残暴”，说不出他具体做过哪件事让读者想看他被了结。
4
故事里的关键事件，是“因为上一件事所以发生了”，还是“然后发生了这件事”？
福斯特的经典区分：故事是“国王死了，王后也死了”；情节是“国王死了，王后死于心碎”。因果链断裂的故事，读者会在中途失去“必须知道接下来”的动力。[reference:3]
删掉任何一个关键情节，后面的故事依然能成立——说明它是堆叠，不是因果。
5
把梗概说给一个不看这类故事的人听，他会不会问“然后呢”？
克龙的核心论点：大脑从第一句开始就渴望“接下来会发生什么”的紧迫感。如果梗概听完，对方只是礼貌地说“挺好的”，没有追问的冲动，说明钩子没扎进去。[reference:4]
听众的反应是“哦，挺完整的”，而不是“那她后来怎么办”。
快速检查的判定规则：五个问题中，如果红灯数量 ≥ 2，这个雏形还不具备写出来的条件，先回到梗概阶段修。如果红灯数量 = 1，可以进入三引擎诊断，但在诊断中重点盯住那台对应引擎。如果零红灯，直接进入引擎诊断，寻找“扣得还不够紧”的地方。
引擎一：抓人 读者是否愿意跟着这个人走
◎ 人物锚定 透镜：麦基「欲望/需求」· 克龙「错误信念」· 福斯特「圆形人物」
读者是否在故事前段就为这个人感到“不该如此”，并且知道她“非要不可”的东西是什么？

透镜 A不公与心疼：麦基的“观众纽带”

麦基把“观众纽带”放在故事材质的第一步——读者必须先在主角身上找到某种值得投入的东西，之后的一切才有意义。[reference:5]克龙补充：这种投入不是“她好可怜”，而是“她本不该承受这个”。
熄火：苦难是设定要求的，读者看不出她凭什么遭罪。惨是概念上的，没有具体画面。
怠速：有不公，但停留在“孤儿”“被灭门”这类概括。读者知道她惨，但没被具体场景击中。
点火：不公是具体的、有画面的、明显超出她应得的。读者能说出“那一刻我替她难受”的具体场景。
让没读过的人看前三分之一，问他“你希望这个主角得到什么”。答得出且方向与故事一致，点火；答“不知道”或“她活该”，熄火。

透镜 B具体欲望与错误信念：克龙的“故事 Genius”

克龙在《故事 Genius》中提出一个关键区分：主角有一个“深藏的欲望”（她以为能填补内心空洞的东西），但一个“根深蒂固的错误信念”阻挡她追求这个欲望。故事的本质是主角在压力下被迫质疑这个错误信念。[reference:6]
熄火：目标全是“拯救”“成长”“寻找自我”这类抽象词。没有可见的错误信念，主角的内心障碍不可见。
怠速：有具体目标，但目标是“她应该要”的。错误信念存在，但只是标签（“她不相信自己”），没有具体的行为表现。
点火：外部目标小到一句说清、具体到能画出画面；错误信念在具体选择中反复起作用，读者能看见她“因为不信某件事而一次次选错”。
用一句话说出主角前三分之一“最想要的东西”，禁用抽象词。再用一句话说出“她因为深信什么而一直得不到这个东西”。两句话都具体，才点火。

透镜 C意外与可信：福斯特的“圆形人物”检验

福斯特给出了一条极其锋利的检验标准：圆形人物让人感到意外，而且是以令人信服的方式。主角如果从头到尾行为完全在读者预料之内，她就是扁平的。[reference:7]
熄火：主角的每一个决定都在读者预料之内。她的“成长”是线性的、可预测的。
怠速：有意外，但意外缺乏可信的伏笔，读者觉得“这不是她会做的事”。
点火：主角在某个关键节点做了让读者意外、但回想起来“对，她就是这样的人”的选择。意外性和可信性同时成立。
问读过的人：“主角有没有哪个决定让你意外？”答“没有”，扁平；答“意外但说不通”，可信性不足；答“意外但想想也对”，圆形。
引擎一只要有任何一个探针熄火，不要进入引擎二。读者不锚定在主角身上，后面的压力和选择都落不到心里。
引擎二：推人 主角是否被一步步逼到墙角
⚡ 压力与因果 透镜：麦基「鸿沟」· 福斯特「因果链」· 斯奈德「节拍升级」
主角是否被一步步逼到墙角，而且每一步都是上一步的必然结果？

透镜 A鸿沟原理：麦基的“预期与结果落差”

麦基的核心引擎是“鸿沟”：角色根据自己对世界的理解采取行动，预期某个结果，但现实给出不同反应，形成落差。故事就是角色不断跨过鸿沟、调整行动、再次遭遇落差的循环。[reference:8]
熄火：主角的行动基本都按预期成功，或者失败是“敌人太强”造成的，不是“她对世界的理解有误”。鸿沟不存在。
怠速：有鸿沟，但鸿沟是外部造成的（“没想到敌人有埋伏”），而不是来自主角的错误信念或认知局限。
点火：每一次鸿沟都迫使主角面对“她之前相信的东西可能是错的”。鸿沟层层递进，从外部麻烦逐渐逼向内心信念。
列出主角的三到五个关键行动，逐个问：她行动前的预期是什么？实际结果是什么？这个落差有没有动摇她之前的某个信念？如果落差只是“运气不好”，鸿沟就是假的。

透镜 B因果链而非编年史：福斯特的“情节”检验

福斯特的区分极其锋利：故事按时间顺序排列，情节按因果逻辑排列。“国王死了，然后王后也死了”是故事；“国王死了，王后死于心碎”是情节。[reference:9]大纲中每一个关键事件，都必须是因为上一件事而发生的，不是“然后发生了这件事”。
熄火：去掉任何一个关键情节，后面的故事依然成立。事件之间是时间顺序，不是因果顺序。
怠速：主干有因果，但支线是“顺便发生的”。读者感觉有些情节是为了凑数或展示世界观。
点火：去掉任何一个关键情节点，后面的链条会垮。每一个事件都是前一个事件的必然结果，同时是下一个事件的原因。
在大纲中逐个删掉情节点，问：删掉这个，后面的情节还能成立吗？能，就是编年史；不能，才是因果链。

透镜 C节拍升级：斯奈德的“风险加码”

《救猫咪》的节拍表本质上是一套节奏诊断工具：从“触发事件”到“中点”到“灵魂黑夜”，风险必须一层层加码，不能停在同一个量级。如果第一场和第十场的赌注一样大，读者会在第五场失去紧张感。[reference:10]
熄火：危机从头到尾一个量级。或者风险是抽象概念（“天下大乱”），读者不觉得主角真的会失去什么。
怠速：危机在升级，但升级靠“敌人变强”，不是“主角在乎的东西被威胁”。
点火：每一次升级都威胁到读者已经在前文爱上的具体的人或东西。失败代价是具体的、有画面的、层层加码的。
把主角在每一幕的处境写成“她必须在X时间内做到Y，否则Z会失去”。如果Z在每一幕都是同一个量级的抽象概念，节拍没有升级。
引擎二熄火，引擎三的“改变”就没有说服力——读者不觉得主角被逼到墙角，也就不觉得她“变成了另一个人”。
引擎三：留人 读者带走的是问题还是遗忘
◇ 改变与余味 透镜：特鲁比「真实自我的揭露」· 哈蒙「故事圈」· 麦基「主控思想」
主角从开始到结束是否变成了一个读者能看见的、不同的、且可信的人？故事结束后，读者带走了什么？

透镜 A真实自我的揭露：特鲁比的“角色转变”

特鲁比把“真实自我的揭露”放在故事结构的末端：主角在经历对决之后，必须获得一个关于自己的、之前不知道的真相。这个揭露不是“她变强了”，而是“她终于看清了自己一直信错的东西”。
熄火：开头和结尾的主角，行为方式没有可对比的变化。或者变化靠台词宣布（“我变了”）。
怠速：有变化，但变化是线性的、可预测的（从弱到强、从怕到不怕）。没有“真实自我揭露”的瞬间。
点火：主角在结局处获得了一个关于自己的具体真相，这个真相动摇了她开篇时的错误信念。变化不是线性的，中间有反复、有错步。
写出主角在开头第一场和结尾最后一场各做的一个动作。如果这两个动作放在一起看不出区别，熄火。再写出她在结局处“看清的关于自己的那一件事”——如果写不出来，真实自我揭露没有发生。

透镜 B故事圈：哈蒙的“代价与回归”

丹·哈蒙的故事圈把叙事压缩成八个步骤：舒适圈 → 渴望 → 进入陌生情境 → 适应 → 得到渴望的东西 → 付出沉重代价 → 回归 → 改变。[reference:12]其中“得到渴望的东西”和“付出沉重代价”是相邻的两步——主角往往在得到她以为想要的东西时，才发现代价是她真正在乎的东西。
熄火：主角得到目标的过程没有付出任何读者能感受到的代价。或者代价与目标无关，像是“作者为了让她惨而加的痛苦”。
怠速：有代价，但代价是抽象的（“她失去了天真”），读者看不见她失去了什么具体的东西。
点火：代价是读者在前文已经爱上的人、关系或物件。她得到目标的同时，失去了一个读者也在乎的东西。改变因此有了重量。
写出主角在结局处“得到了什么”和“失去了什么”。如果失去的东西是一个抽象名词，代价就是假的；如果失去的是一个具体的人或物，但读者在前文没见过它被珍视，代价也落不了地。

透镜 C主控思想与选择感：麦基的“反宿命”

麦基的“主控思想”不是故事的道理，而是故事在结尾处证明的那个价值判断。它必须从高潮的选择中生长出来，而不是靠台词宣布。同时，结局必须是主角“选择”的，而不是“命运安排”的——读者要感到“她本可以不这么做”。[reference:13]
熄火：主题靠角色在结尾说一句点题台词来宣布。删掉那句台词，读者说不出故事讲了什么。或者结局是宿命驱动的：“她注定”“她不得不”。
怠速：主题能在情节中找到支撑，但支撑是分散的。结局有选择，但“两害相权取其轻”，读者不震撼。
点火：删掉所有点题台词，读者仍能说出“这个故事在讲什么”。结局面前有一条“看起来很合理”的退路，她没走。读者同时感到“她真傻”和“她真了不起”。
删掉故事中所有点题台词和旁白议论，问没读过的人“你觉得这个故事在讲什么”。答得出，主控思想生长出来了。再写出主角在结局面前的“另一条路”——写不出来，选择感就是假的。
引擎三是最后一台。它不依赖前两台“扣得紧不紧”，但它依赖前两台“有没有在转”。前两台熄火，引擎三写得再好也只是漂亮的空转。

综合诊断流程：怎么用这套体系

不要从引擎三倒着修，也不要同时修三台。诊断顺序永远是从引擎一到引擎三，修的顺序也是。

1
先跑快速检查（5 个问题）
红灯 ≥ 2：回到梗概阶段，先修红灯对应的问题。红灯 = 1：进入引擎诊断，但重点盯住那台对应引擎。红灯 = 0：进入引擎诊断，寻找“扣得不够紧”的地方。
如果快速检查就亮了两盏以上红灯，不要浪费时间做详细引擎诊断。雏形的核心驱动力还没建立。
2
诊断引擎一：读者是否在乎主角？
用三个透镜（麦基的观众纽带 / 克龙的欲望与错误信念 / 福斯特的圆形人物）逐一检查。任何一盏熄火，停在这里修。
如果引擎一熄火，不要去看引擎二。主角没锚定，压力和选择都是空转。
3
诊断引擎二：压力是否在升级，因果是否成立？
用三个透镜（麦基的鸿沟 / 福斯特的因果链 / 斯奈德的节拍升级）逐一检查。鸿沟是否迫使主角质疑自己的信念？事件之间是因果还是编年？风险是否层层加码？
如果引擎二熄火，不要去看引擎三。读者不觉得主角被逼到墙角，就不觉得她的改变有分量。
4
诊断引擎三：改变是否可信，余味是否落地？
用三个透镜（特鲁比的真实自我揭露 / 哈蒙的代价与回归 / 麦基的主控思想与选择感）逐一检查。主角是否看清了关于自己的真相？她得到目标时失去了什么读者在乎的东西？结局是她选的，还是命定的？
如果引擎三熄火，问题往往不在引擎三本身，而在引擎一或引擎二的某一环没扣紧。回头检查，不要只在结尾加台词。
熄火引擎典型症状优先修什么
引擎一读者说“我没什么感觉”“不知道她想要什么”具体的不公场景 + 可见的错误信念 + 一个让读者意外的选择
引擎二读者说“有点拖”“不知道反派想干嘛”“这段可以跳过”鸿沟链（预期 vs 结果的落差）+ 删掉非因果情节点 + 让风险落到具体的人或物上
引擎三读者说“挺好看的，但看完就忘了”真实自我揭露的瞬间 + 具体的代价 + 一条“她本可以不走”的退路

一个重要的诊断原则：如果引擎三出了问题，先不要修引擎三。绝大多数“结尾没力量”的故事，病根在引擎一（读者不够在乎主角）或引擎二（压力没有真正逼到主角的信念上）。修引擎三之前，先回头确认前两台引擎是否真的在转。

麦基：鸿沟 / 压力下的选择 / 主控思想角色的预期与结果之间有没有落差？结局是她选的还是命定的？引擎二的透镜 A；引擎三的透镜 C
克龙：错误信念 / 大脑紧迫感 / 欲望与需求主角因为深信什么而一直选错？第一页有没有让大脑想知道“然后呢”？引擎一的透镜 B；快速检查第 1、5 题
福斯特：因果 vs 编年 / 圆形人物事件之间是“因为”还是“然后”？主角有没有让人意外且可信的选择？引擎二的透镜 B；引擎一的透镜 C
特鲁比：弱点 / 对手 / 真实自我揭露主角开篇有什么道德弱点？对手是不是在争夺同一个目标？结局她看清了什么？引擎三的透镜 A；快速检查第 3 题
斯奈德：节拍升级 / 风险加码风险有没有一层层变大？赌注有没有从抽象变成具体？引擎二的透镜 C
哈蒙：故事圈 / 代价与回归她得到想要的东西时，失去了什么读者在乎的东西？引擎三的透镜 B

这些透镜不是互斥的，而是从不同角度照射同一个问题。一个故事可以在麦基的透镜下“鸿沟不够”，在克龙的透镜下表现为“错误信念没有被真正挑战”，在福斯特的透镜下表现为“中间事件是编年而非因果”。诊断时交叉使用，定位会更准。
